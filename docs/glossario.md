# Glossário: termos do TCC ↔ código

| Termo no TCC (pt-BR) | Código (inglês) | Tabela |
|---|---|---|
| Usuário / paciente | `User` | `users` |
| Cartão de enfrentamento | `CopingCard` | `coping_cards` |
| Grupo de cartões | `CopingCardGroup` | `coping_card_groups` |
| Registro de pensamento | `ThoughtRecord` | `thought_records` |
| Sentimento / emoção | `Emotion` | `emotions` |
| Intensidade do sentimento (0–100%) | `intensity` em `ThoughtRecordEmotion` | `thought_record_emotions` |
| Relatório salvo | `SavedReport` | `saved_reports` |
| Evolução das emoções (gráfico do relatório) | `EmotionTrend` | — (calculado) |
| Código de confirmação (e-mail) | `VerificationCode` | `verification_codes` |
| Cadastro pendente (aguardando o código do e-mail) | `PendingRegistration` | `pending_registrations` |
| Confirmação do cadastro | `registration` (propósito do código) | — |
| Exclusão de conta | `account_deletion` (propósito do código) | — |
| Redefinição de senha ("Esqueci a senha") | `password_reset` (propósito do código) | — |
| Conteúdo educativo (aba Educação) | `education` (feature do app, conteúdo local) | — |
